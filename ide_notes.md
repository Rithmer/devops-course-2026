# Git в VS Code

## Что удобно в VS Code

1. Удобно видеть список изменённых файлов.
2. Можно визуально сравнивать изменения через diff.
3. Огромное количество расширений.

## Что удобнее делать в терминале

В терминале удобнее выполнять сложные Git-команды, потому что доступны все возможности Git и хорошо видно результат выполнения команд.
