# Сравнение Git и SVN

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git ветки создаются быстро и практически не требуют дополнительных ресурсов, потому что Git работает с указателями на коммиты. В SVN ветвление исторически связано с созданием копий каталогов в централизованном репозитории, поэтому работа с ветками менее удобна.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет, для обычного коммита SVN требуется доступ к центральному серверу, потому что SVN является централизованной системой контроля версий. В Git коммиты можно создавать локально без подключения к интернету.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

SVN может использоваться в старых корпоративных и государственных проектах, где инфраструктура уже построена вокруг SVN. Также переход большого существующего проекта на Git может потребовать дополнительных затрат и изменений процессов.
